# Changelog

## [1.0.4.2] - 2026-07-01

### Исправлено

- Регрессия под Windows (тонкий клиент x64): объект компоненты перестал создаваться на платформе 8.3.21+. Причина — `GetAttachType()` возвращал `eCanAttachAny`, из-за чего 1С по умолчанию подключала компоненту изолированно, а в изолированном процессе работа с буфером обмена не поддерживается. Возвращено `eCanAttachNotIsolated` — компонента снова подключается в адресном пространстве клиента.

## [1.0.4.1] - 2026-07-01

### Изменено

- Сборка под Mac с архитектурой ARM.

## [1.0.4.0] - 2026-05-21

### Добавлено

- Первая версия внешней компоненты для конфигурации "Управление IT-отделом 8". Но на самом деле подойдет для любой конфигурации 1С, которые поддерживают внешние компоненты NativeAPI.
