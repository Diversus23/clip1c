## ClipboardControl — внешняя компонента для работы с буфером обмена

Поддерживается под Windows, Linux и macOS.

### Подключение внешней компоненты

```bsl
&НаКлиенте
Перем БуферОбмена;

&НаКлиенте
Процедура ПодключениеВнешнейКомпонентыЗавершение(Подключение, ДополнительныеПараметры) Экспорт
    БуферОбмена = Новый("AddIn." + ИдентификаторКомпоненты + ".ClipboardControl");
КонецПроцедуры
```

### Свойства

- Текст / Text — текстовое содержимое буфера обмена
- Картинка / Image — изображение (PNG, двоичные данные)
- Файлы / Files — JSON-массив путей к файлам в буфере
- Формат / Format — JSON со списком форматов в буфере
- Мониторинг / Monitoring — флаг отслеживания изменений буфера (только Windows)
- Версия / Version — версия компоненты

### Методы

- ЗаписатьТекст / SetText
- ЗаписатьФайлы / SetFiles
- ЗаписатьКартинку / SetImage
- Очистить / Empty
